# 音乐播放器 (MusicPlayer)

一个干净、轻量、**无广告** 的本地音乐播放器。只做一件事：播放你自己手机里的音乐，不打扰你。

## 为什么选择它

- **没有任何广告**，也没有任何形式的推广位、开屏广告、推送广告
- **完全离线**，不申请网络权限，不联网、不收集任何个人数据
- **不下载歌曲**，只扫描并播放设备本地已有的音乐文件
- **永久免费**，代码开源，想改就改

## 功能特性

- 📂 **本地音乐扫描**：自动扫描设备上的音乐文件，仅首次启动时扫描，之后秒开无需等待
- 🎵 **所有歌曲 / 歌单**：底部导航切换全部歌曲与自建歌单，随手把喜欢的歌收进歌单
- ▶️ **完整播放控制**：播放/暂停、上一首、下一首、拖动进度条
- 🔁 **两种播放模式**：顺序播放、单曲循环
- 🎧 **后台播放**：支持通知栏播放控制，锁屏也能继续听
- 🖥️ **迷你播放条**：主界面底部常驻迷你播放条，随时切歌
- 🗑️ **移除歌曲 ≠ 删除文件**：从 App 中移除歌曲只会把它从播放清单中移除，不会动设备上的音乐文件
- 📏 **智能过滤**：自动过滤时长小于 30 秒的音频文件

## 技术栈

- Kotlin + Android 原生开发（minSdk 24 / targetSdk 34）
- MediaStore 扫描本地音乐，MediaPlayer 播放
- Material Design 3 风格界面，ViewBinding 绑定视图
- 歌曲列表与歌单使用本地 JSON 持久化，不依赖任何服务器

## 构建

```bash
# 构建 Debug APK
./gradlew assembleDebug
# 产物路径：app/build/outputs/apk/debug/app-debug.apk
```

仓库已配置 GitHub Actions，每次推送到 `main` 分支会自动构建 APK 并上传为构建产物。

## 隐私说明

本 App 不需要任何网络权限，不包含广告 SDK、统计 SDK、推送 SDK。唯一需要的权限是读取本地音频文件的权限，所有数据都只保存在你自己的手机上。
